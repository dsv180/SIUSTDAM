# Что сделать после pull на второй машине (чек-лист деплоя)

> Файл лежит в репозитории специально: после `git pull` агент сразу видит,
> что нужно сделать, чтобы изменения заработали в рантайме. Выполняйте по
> порядку. Шаг 0 — только если на машине ещё не было развёртывания
> (`ИНСТРУКЦИЯ-АГЕНТУ-ОБНОВЛЕНИЕ-РЕПОЗИТОРИЯ.md`).

## 1. Обновить настройки шлюза в корне стыка

Начиная с коммита `c4ac4c0` в репо лежит актуальный `gateway-config.yaml`
(эмбеддинги включены). Git не видит файлы ВНЕ папки репозитория, поэтому
скопируйте его на уровень выше — в корень стыка:

```cmd
deploy\copy-config.cmd
```

(скрипт перезаписывает `C:\TDAM\gateway-config.yaml`; путь стыка — соглашение
пакета, см. `ИНСТРУКЦИЯ-АГЕНТУ-ОБНОВЛЕНИЕ-РЕПОЗИТОРИЯ.md`)

## 2. Зависимости ядра

```cmd
cd /d C:\TDAM\agent-memory\MemoryCore
npm install
```

(приедет зависимость `snowball-stemmers`, если ещё не стоит)

## 3. Пересборка панели

```cmd
cd /d C:\TDAM\agent-memory\MemoryPanel\web
npm run build
```

(без этого панель продолжит показывать старую сборку — в том числе старую
локаль; интерфейс останется с английскими формами)

## 4. Рестарт сервисов

```cmd
powershell -NoProfile -ExecutionPolicy Bypass -File C:\TDAM\gateway-service.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File C:\TDAM\mcp-http-service.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File C:\TDAM\memory-web-service.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File C:\TDAM\panel-service.ps1
```

(лаунчеры идемпотентны: живой сервис не трогают — перед рестартом шлюза
остановите слушателя порта 8420: `taskkill /PID <pid> /F`, где pid из
`netstat -ano | findstr :8420`)

## 5. Проверка

```cmd
curl http://127.0.0.1:8420/health
```
Ожидается: `"status":"ok"`, `"ftsAvailable":true`, `"embeddingService":true`.

Панель `http://127.0.0.1:8123` — формы на русском; поиск по памяти находит
свежие записи.

## Напоминание о секретах

`gateway.env` с ключами через репозиторий не передаётся (правило: ключи не
уезжают без особого подтверждения владельца). Если ключей на машине нет —
владелец передаёт их отдельно, любым согласованным способом.
