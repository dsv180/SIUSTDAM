# Интерактивная документация TDAM (веб-комплект)

Самодостаточная браузерная документация по TDAM / SIUSTDAM: принципы работы,
архитектура, развёртывание, руководство Memory Hub, наши доработки, регламенты,
находки и справочник команд.

## Состав

| Файл/папка | Что это |
|---|---|
| `index.html` | Документация (открывается двойным кликом, работает офлайн) |
| `диаграммы/` | 5 схем Archify (архитектура, конвейер записи, контур чтения, гибридный поиск, srv-1-1) |
| `скриншоты/` | Снимки панели Memory Hub для раздела «Руководство» |
| `server.mjs` | Мини-сервер статики: `node server.mjs [порт]` (по умолчанию 8788) |

## Как открыть

- **Локально**: двойной клик по `index.html` — интернет не нужен.
- **По сети**: `node server.mjs` в этой папке → `http://<адрес-машины>:8788/`.

На сервере SRV-1-1 комплект раздаётся службой **TDAM-Docs** (NSSM, порт 8788,
обёртка `D:\TDAM\docs-run.ps1`, логи `D:\TDAM\logs\docs-*.log`), комплект лежит
в `D:\TDAM-Документация\интерактивная-документация`.

## Правила

- Секретов в комплекте нет (только имена файлов и переменных окружения).
- Обновлять при изменении системы; источник правок — рабочая папка проекта.
