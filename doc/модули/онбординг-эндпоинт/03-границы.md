# 03-Границы: онбординг-эндпоинт

> **Предыдущий:** [02-задание.md](<02-задание.md>)

## Входит

- Маршруты `/connect/*` (5 шт., §3 задания) и файлы контента per-agent.
- Секция `connect` в конфиге шлюза с fallback (без неё маршруты работают).
- Мост в составе шлюза — копия с фиксом `isDirectInvocation` (realpath, 06.11).

## Не входит (осознанно, с триггерами возврата)

| Не входит | Почему | Триггер возврата |
|---|---|---|
| user_key-гейт на `/connect/*` | полигон публичный, секретов в манифесте нет | вынос TDAM на сервер (К5) |
| Перенос контента в skill-хранилище | К1–К4 не должны зависеть от необкатанного канала | после стабилизации skill-канала |
| Фикс realpath моста в источнике ZCode-плагина | правка стороннего пакета плагина — отдельная работа | следующая ревизия плагина sius-memory-tdai |
| LLM-прокси-канал (MemoryProxy) | другая тема, развязано решением 06.11 | отдельный модуль |
| Карточки /connect в панели Memory Hub | панель — человеческий пульт, агенту URL выдаёт человек; дубль интерфейса | если появится потребность «панель выдаёт URL подключения» |
| Автоперезапуск агента из манифеста | агент не может перезапустить себя; честная ручная ступень | никогда (принципиальная граница) |
| Мультиинстансность (`{instance}` проверка) | шлюз однИнстансный | multi-instance в ядре |

## Допущения

1. Агент умеет: HTTP GET (curl/инструмент), правку файлов, запуск команд —
   верно для ZCode и DSH; новые агенты с меньшими способностями потребуют
   перебора транспорта (поле `transport.kind` в манифесте задел на это).
2. Host-заголовок на полигоне достоверен; за прокси — `connect.baseUrl`.
3. Контент манифеста не содержит секретов (проверять при каждой правке).
