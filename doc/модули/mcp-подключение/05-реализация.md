## Этап 1 — перенос работающего

- **Вшитый MCP-эндпоинт шлюза**: `MemoryCore/src/gateway/mcp-endpoint.ts`
  (новый файл, `[pilot-patch]`) + блок вызова в `server.ts`.
  `POST http://<шлюз>:8420/mcp` — streamable-http, stateless JSON;
  минимальный протокол вручную (SDK в MemoryCore нет): initialize,
  notifications/initialized, tools/list, tools/call, ping + проприетарный
  зонд ZCode `server/discover`.
- Инструменты идут через **собственные v3-обработчики шлюза** (карта
  V3_HANDLERS → handleAtomicSearch/Query/Count, handleConversation*/,
  handleScenario*/), изоляция на каждый вызов: тело (idFields, как
  передаёт панель) + deps.requestIsolation (поисковые фильтры), как
  делает dispatchV2Request для HTTP /v3/*.
- Дефолты изоляции: заголовки x-tdai-* запроса → TDAI_MCP_TEAM_ID /
  TDAI_MCP_AGENT_ID / TDAI_MCP_USER_ID (gateway.env) → "default".
- Хуки ZCode (session-start, user-prompt, tool-hooks) переведены на
  минимальный MCP-клиент `mcp-client.mjs` (deploy/scripts + C:\TDAM);
  тихая деградация 8 с; CLI из хуков исключён.
- Приёмка: initialize/tools/list/живой поиск; результаты идентичны
  прямому v3; хуки прогнаны живьём; смоук-запись в пространстве команды.

## Этап 2 — новые инструменты (W2 + W4)

Группа 1 — подключение агентов:
- `memory_connect` {agent_name, description?, user_id?} — находит агента
  по имени в команде или создаёт (MetadataService.createAgent, который
  сам регистрирует chat_memory-актив), возвращает team_id/agent_id/user_id.
- `memory_whoami` — текущее пространство + имя агента (по метаданным) +
  счётчики L0/L1.
- `memory_get_rules` — правила и дисциплина работы с памятью (текст
  встроен; принцип положительного контракта).

Группа 3 — обзорные:
- `memory_persona` (L3 core/read), `memory_scenes` (L2 ls), 
  `memory_scene_read` {path} (L2 read), `memory_stats` (счётчики
  L0–L3 через count-эндпоинты), `memory_recent` {limit} (последние L0).
- Канал инструментальных ошибок: `error_lessons` {query?, limit?} —
  уроки (work_method; без query — все через atomic/query, с query —
  релевантные через atomic/search), `error_recent` {limit?} — последние
  ошибки (conversation/search). Конвейер канала (модуль «канал-ошибок»)
  не переизобретается — только обзорный слой.
