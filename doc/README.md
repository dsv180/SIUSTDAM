# doc/ — документация слоя TDAM (наша надстройка)

Здесь лежат документы **нашей** надстройки над авторским проектом
TencentDB Agent Memory (правки `[pilot-patch]`). Авторская документация —
в корне репозитория и в `MemoryCore/`, `MemoryPanel/` и т.д.

---

## С чего начать

**Порядок чтения — от основ к частному:**

| # | Документ | Что это | Кому |
|---|---|---|---|
| 1 | `основы-агентской-инфраструктуры.md` | **Основополагающий.** Базовые принципы, к которым не возвращаются | всем |
| 2 | `стандарт-работы-с-памятью.md` | Условия работы с памятью (эталон, без команд и путей) | агентам, настройщикам |
| 3 | `правила-памяти-zcode.md` | Адаптер ZCode: готовая вставка в `AGENTS.md` | агенту/админу ZCode |
| 4 | `правила-памяти-dsh.md` | Адаптер DSH (цель — TDAM, не engram) | агенту/админу DSH |

**Установка и обновление** (отдельная линия — развёртывание системы):

| Документ | Что это |

| `ИНСТРУКЦИЯ-АГЕНТУ-ОБНОВЛЕНИЕ-РЕПОЗИТОРИЯ.md` | Инструкция агенту по обновлению репозитория |

## Иерархия (кто кого перекрывает)

```
основы-агентской-инфраструктуры.md      ← высший уровень, принципы
        ↓ (следствия)
стандарт-работы-с-памятью.md            ← условия работы с памятью
        ↓ (реализация)
правила-памяти-<клиент>.md              ← адаптеры под конкретные клиенты
```

План развития и развёртывания ведётся во внутреннем документе
(вне git) — он содержит специфику конкретной установки.

**Правило расхождений:** при противоречии документов верен тот, что выше.
Адаптер правится под стандарт; стандарт — под основы; основы меняются
только решением заказчика.

---

## Быстрые факты (чтобы не искать заново)

**Специфичные для места установки значения (адреса, порты, пути) здесь
намеренно не приводятся** — они зависят от развёртывания и лежат во
внутреннем документе (вне git).

| Что | Где смотреть |
|---|---|
| Установка и обновление | `install_ru.md`, `ОБНОВЛЕНИЕ-НА-ВТОРОЙ-МАШИНЕ.md` |
| API шлюза (v3, 109 эндпоинтов) | `MemoryCore/v3-api-memorycore-doc.md` |
| Общая схема настройки клиента | `правила-памяти-<клиент>.md`, раздел «Технические детали» |
